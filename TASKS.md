## Decisions (7 Oct 2026)

- **Free stays free.** Everything that works in 1.1 keeps working without paying. The theme switch moves from the header to About → Theme (handoff #5) — it stays free, it only moves.
- **Purchases go directly through Apple (StoreKit 2 via `expo-iap`). No RevenueCat, no analytics, no accounts** — the App Privacy label "Data Not Collected" must stay true.
- **Products** (Cowork/Vlad create them in App Store Connect; ids are fixed):
  - `com.filonexperiencedesign.mocktailfinder.pro` — non-consumable, 5.99 € — Pro tools
  - `com.filonexperiencedesign.mocktailfinder.everything` — non-consumable, 12.99 € — Pro + every collection, now and later
  - `com.filonexperiencedesign.mocktailfinder.pack.dryjanuary` / `.pack.eveningclassics` / `.pack.winterwarmers` / `.pack.summergarden` / `.pack.tropicalescape` / `.pack.partybrunch` — non-consumable, 2.99 € each (the `productId` of each pack in `recipes.json`)
  - `com.filonexperiencedesign.mocktailfinder.tip.small` / `.tip.medium` / `.tip.large` — consumable, 4.99 / 9.99 / 19.99 €, "Lemonade" / "Smoothie" / "Punch"; they unlock nothing
  - `isPro = owns(pro) || owns(everything)` · `collectionOpen(id) = owns(everything) || owns(pack.id)`
- **Answers to the handoff's open questions** (confirmed by Vlad, 7 Oct 2026):
  1. Pending (Ask to Buy) and failed purchase copy: as proposed in README → Open questions, both languages. Pending shows a toast and leaves the thing locked; it unlocks when the transaction arrives (listen for updates on every launch).
  2. Family Sharing: **on** for Pro, Everything and the six collections (set in App Store Connect; in code nothing special — `currentEntitlements` already includes family-shared transactions). Tips are consumable, no sharing.
  3. Refund / revoked purchase: **lock again silently** (drop entitlements with `revocationDate`). No message.
  4. "Show tips again" / replay the tour: **debug builds only** (DEV switches on About). Not in the public UI in 1.2.
  5. Product ids: confirmed as listed above. The old `pack.classics` id from earlier notes is gone.
- **Catalogue source stays as in 1.1:** the 58 TheCocktailDB drinks come from the API + details cache. The `catalogue` entries in `recipes.json` are a reference (ids, tags, ingredient keys), not a second data source. The six collections come from `recipes.json`.
- **Ukrainian for the 58 catalogue drinks:** delivered by Cowork on 7 Oct as `src/data/uk/drinks.json` (Vlad is reviewing; small text edits may follow). Shape: `{ "<idDrink>": { name, glass, ingredients: [{ measure, name }] (same order and count as the API drink), instructions } }`. Merge per field over the API data when the language is `uk`, falling back to English for any missing id or field. Ukrainian measures are metric (ml, г, л, ч. л., ст. л., склянка) with the number first, so servings scaling works unchanged; descriptors ("cold", "instant") moved into the Ukrainian ingredient name. Ingredient keys for My Bar are derived from the English names only. Pack recipes are already bilingual in `recipes.json`.
- **Apple review rules:** prices only from StoreKit (`displayPrice`), never typed; a visible **Restore Purchases** on the paywall, the collection sheet and About; no mention of other ways to pay; consumables finished after purchase; the paywall never appears uninvited and never blocks a free feature.
- **Dependencies pre-approved** (ask before any other): `expo-iap` (StoreKit 2), `expo-localization` + `i18n-js` (language), `react-native-view-shot` (share card). `react-native-gesture-handler` is already installed (swipe to delete). If you need `react-native-reanimated`, ask first. No software of Russian origin.
- **Testing reality:** `expo-iap` is a native module, so **Expo Go cannot run it.** The app must not crash in Expo Go: wrap the store in a try/catch "store unreachable" state (the handoff designs that state everywhere). For simulator work use a development build (add a `development` profile with `"ios": { "simulator": true }` to `eas.json`; Vlad runs `npx eas-cli@latest build --profile development --platform ios` after his ok, then `xcrun simctl install booted <app>`; `npx expo run:ios` is fine too if CocoaPods is available). Real purchase flows are tested by Vlad in TestFlight / sandbox (see `TESTING.md`). DEV switches (long-press 800 ms on the version line in About, `__DEV__` only): simulate Pro, Everything, each collection, store unreachable, reset tour and hints.
